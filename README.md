# 中文自定义字帖生成器

一款专为中文练字设计的字帖生成工具，支持自定义内容、多种排版模式和字体选择，完美适配 A4 打印。

## ✨ 功能特性

### 核心功能
- **自定义内容**：输入任意汉字、诗词、文章
- **两种排版模式**：
  - 散文格式：全文连续排版，从左到右、从上到下
  - 诗词格式：每行文本严格对应一行格子，标题自动居中，正文顶格，不足补空
- **循环重复**：内容显示完后自动循环，支持反复练习
- **三种格子类型**：米字格、田字格、方格
- **多种字体**：楷体、宋体、黑体、仿宋、隶书、幼圆，以及行楷、欧体、颜体等书法字体
- **灵活调节**：
  - 每行字数：1-20 字可调
  - 每页行数：1-30 行可调
  - 字号比例：60%-95% 可调
  - 格子大小：自动适配或手动设置（1-100mm）
- **描红功能**：红色示例字 + 空心练习字，支持开关
- **A4 打印**：完美适配 A4 纸张（210×297mm），打印尺寸与预览一致

### 其他特性
- **自动保存**：所有设置自动保存到浏览器，下次打开自动恢复
- **离线使用**：纯前端实现，无需联网，双击 HTML 即可使用
- **打印优化**：支持颜色精确打印，格子边框清晰

## 🚀 使用方法

### 方式一：直接打开
双击 `index.html` 文件，在浏览器中打开即可使用。

### 方式二：本地服务器（推荐）
```bash
# 使用 serve
npx serve -l 3000

# 或使用 Python
python -m http.server 3000

# 或使用 Node.js http-server
npx http-server -p 3000
```

然后在浏览器访问 `http://localhost:3000`

### 使用步骤
1. 输入练习内容（如诗词、文章）
2. 选择排版模式（散文格式/诗词格式）
3. 选择格子类型（米字格/田字格/方格）
4. 选择字体和字号
5. 调整每行字数和每页行数
6. 点击"生成字帖"预览
7. 点击"打印字帖"打印（选择"实际大小"或"100%"缩放）

## 📋 打印设置

为确保打印效果与预览一致，请在打印对话框中设置：
- **缩放**：选择"实际大小"或"100%"，不要选择"适应页面"
- **纸张**：A4（210×297mm）
- **边距**：无或最小

## 💡 使用技巧

### 诗词格式
- 输入格式：
```
乙卯重五诗 陆游
【宋】陆游
重五山村好，榴花忽已繁。
粽包分两髻，艾束著危冠。
旧俗方储药，羸躯亦点丹。
日斜吾事毕，一笑向杯盘。
```
- 选择"诗词格式"，第一行（标题）会自动居中，后续行顶格对齐
- 每行诗对应一行格子，不足自动补空（格子隐藏）
- 标题行示例：输入"乙卯重五诗 陆游"（7 字），选择 8 格时，整体会居中显示，不会截断
- 勾选"循环重复"，显示完所有诗句后会自动循环

### 散文格式
- 所有内容（包括换行）会连在一起连续排版
- 适合文章、段落练习

### 大字练习
- 选择"每行 4 字"或更少
- 格子大小调至 40-60mm
- 适合初学者练习基本笔画

### 小字练习
- 选择"每行 10-20 字"
- 格子大小会自动缩小
- 适合进阶练习

## 🎨 字体说明

### 系统自带字体（无需安装）
- 楷体（KaiTi）
- 宋体（SimSun）
- 黑体（SimHei）
- 仿宋（FangSong）
- 隶书（LiSu）
- 幼圆（YouYuan）

### 书法字体（需安装）
- 行楷（STXingkai）
- 欧体（Ouyang Xun Ti）
- 颜体（Yan Zhenqing Ti）
- 柳体（Liu Gongquan Ti）
- 赵体（Zhao Mengfu Ti）
- 瘦金体（Shoujin Ti）

如系统未安装书法字体，会自动回退到楷体。
